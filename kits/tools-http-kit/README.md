# tools-http-kit

HTTP request tool via httpx.

## Dependencies

- `httpx>=0.27`

## Tools

| Name | Description |
|------|-------------|
| http_request | HTTP request |

## Usage

Install and initialize Beddel:

```
pip install beddel && beddel init
```

The kit is auto-discovered by the Beddel engine when its dependencies are installed.
